# TodoList
A full-featured task management application for organizing projects, tasks, and subtasks in one place.

The application provides user authentication, project and task management, drag-and-drop interactions, customizable tags, deadlines, reminders, and file attachments.

Built with React and TypeScript, following Feature-Sliced Design (FSD) and BEM methodologies.

## ✅ Features
#### Authentication & Account Management
➕ Email and password authentication

➕ OAuth authentication via GitLab and Google

➕ Password recovery and password changes

➕ Email notifications

➕ User profile management

#### Project Management
➕ Create, edit, and archive projects

➕ Paginated project lists

➕ Search and filtering

#### Task & List Management
➕ Create and manage task lists within projects

➕ Create tasks displayed as information-rich cards

➕ Drag and drop tasks between lists

➕ Search and filter tasks

➕ Archive tasks and projects

#### Task Details
➕ Create and manage subtasks

➕ Add tags to tasks

➕ Attach files

➕ Add task descriptions

➕ Set deadlines and reminders

#### Archive
➕ Separate archive for tasks and projects

➕ Automatic deletion of archived items after a specified period

#### User Profile

➕ Edit personal information

➕ Manage tags and other profile settings

#### Responsive Design

➕ Adaptive interface for desktop, tablet, and mobile devices
